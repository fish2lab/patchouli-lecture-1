# 第三版修改：开场重做，睡眠和吃饭各修一处

2026-09-25 用户审看 v0.2.0 后提了三点：开头不够好看；睡眠段有一段光线错打在帕秋莉身上，光和太阳接得不好；吃饭段一勺糖，糖和勺子的位置对不上。另请顺带看看还有什么建议。

## 开场的头几秒决定观众愿不愿意看下去，现在这几秒太平

现状（v0.2.0，`src/scenes/0-opening.js`）：
- 0–2.3 秒：深色桌面上一块没有厚度的暗红梯形，看不出是一本书。
- 封面：一张平的暗红纸、一圈细金线、一弯月牙、「帕秋莉讲座」五个字，像占位图。
- 封面翻开：一张矩形横向压扁，没有透视。
- 标题页：左页只有一弯月牙，右页居中两行黑字，大片空着。
- 后面 L7 的三个涂鸦（手机是黑方块、椅子是一个「h」、外卖袋是梯形）太简陋。

照着抄的范本：迪士尼经典片头的「故事书开场」（《白雪公主》1937、《睡美人》1959）——桌上一本皮面烫金的厚书，镜头推近，书自己打开、自己翻到这一页，页上的字浮现出来。本系列是剪纸 + 墨线，照这个结构做，画法沿用 `docs/画风v2.md`（纸、墨、几级灰、一种紫、月牙金；不用发光）。

新的前 8 秒：
1. **桌上的书是一件真东西**：斜看的桌面上躺着一本厚魔导书，能看到书页的厚边、书脊上的竹节、四角铜包角、一条铜扣带扣住书口、底下露出一截紫色书签丝带。桌上有生活痕迹：墨水瓶和羽毛笔、茶杯和一圈茶渍、角落一小摞书。镜头从斜看慢慢转到正上方。
2. **封面上的烫金是帕秋莉自己的纹章**：她是「七曜魔女」，金墨一笔笔画出双线边框和角花，中间一个七芒星魔法阵，七个角依次亮出「日 月 火 水 木 金 土」，阵心是月牙；下面写「帕秋莉讲座 · 第 1 集」。
3. **铜扣「咔」一下弹开，封面带透视翻开**：翻到一半离镜头最近、最大；翻过去露出封面内侧的大理石纹衬纸和藏书票「Ex Libris · 大图书馆」。
4. **书自己哗哗翻几页，停在标题页**：左页是淡墨画的七曜魔法阵慢慢转，右页是正式的扉页排版（小字系列名、两道细线、大字标题、一条带月牙的花饰分隔线、页底「红魔馆 · 地下大图书馆 藏」）。然后帕秋莉从页底探头：「……看什么看。」

后面 L1–L7 的内容和节奏不动，只把 L7 的三个涂鸦重画得像样（熬夜：被窝里亮着的手机、2:00；久坐：椅子上瘫着的小人；外卖：带小票和热气的外卖袋）。

片尾合上的书要和开场是同一本书（漫步主题回归），所以封面的皮面、边框、铜包角、书页厚边做成 `kit.js` 里的共用函数，开场和总结都用它；总结的封面上仍然写演职信息，不画大魔法阵。

取舍：开场的台词起点可以往后挪（最多约 1 秒）给标题留出读的时间，台词不改字。

## 睡眠：光带从太阳背后发出，只照小人和窗

- 删掉 L4 末尾光带转到帕秋莉身上、她拿书挡脸的那个笑点：看片时读不出是故意的，像错误。
- 光带只在太阳越过远山之后出现（原来太阳还在山后，光带就从山坡上凭空长出来）。早晨的钟点调高一点，让太阳在光带出现前完整露出来。
- 光带画完后把太阳再盖一层，光就像从太阳背后发出来，不再压在太阳脸上。

## 吃饭：勺头停在咖啡杯正上方，糖从勺里倒进去

- 原来勺柄朝杯子、勺头朝外，糖粒却从杯口正上方凭空落下；「倾倒」只是勺子在桌面平面里转了个角度。
- 改成勺头停在杯口正上方、勺柄朝它飞来的右上方；倾倒是绕勺子长轴翻过去（俯拍看就是勺面变窄），勺里的糖粒一颗颗变少，同时从勺头位置落进杯里。

## 顺带审片：修了 5 处会被当成错误的，另 7 处留作建议

2026-09-25 另开一个代理把开场以外的部分逐段抽帧审了一遍，找到 12 处；主会话逐条看证据帧核实后，把「看片时会被当成错误」的 5 处直接修了：

1. 睡眠 L11：帕秋莉从「6–8 小时」吊牌上起身，先站起来再往上跳，头被顶檐切掉约 0.3 秒 → 往下换位置时保持原姿势掉下来，落地后再做这一拍的动作。
2. 睡眠 → 吃饭：推月亮时没算上天空层本来的放大，月亮比交接圆盘大一圈，交叉淡化时还暗一档 → 按实际放大倍数推到半径 300；夜色只盖月亮外面。
3. 所有翻页（`kit.js` 的 `turnPage`）：翻过去的纸背比左页暗一档，落下那一帧左页突然变亮 → 快落平时纸背渐渐变成左页的纸色和阴影。
4. 运动 → 总结：帕秋莉和页眉在段首翻页之前就出现，被翻页盖住后又闪回来 → 帕秋莉等翻页落下后从书页上立起来；第一次页眉删掉（快速翻页后本来还会写一次）。
5. 动力开头：那根线上有一个台阶，书堆摊平时又往地面下凹一个方坑 → 落点跟着横线起伏，摊平系数不小于 0。

留作建议的 7 处（构图和可读性，改不改看取舍）见汇报。
