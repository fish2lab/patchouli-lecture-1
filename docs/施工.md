## 第二版接口

- 每帧先 `spread(c, tau)` 画桌面和摊开的魔导书，`BOOK.L` / `BOOK.R` 是左右页 `{x, y, w, h}`，书脊在 `CX`。段首 0.4 秒内出页眉 `pageHeader(c, '第一页 · 睡眠', tau, .2)`。段与段之间的翻页由 `film.js` 在段首 0.8 秒画（`turnPage`），段首第一帧就应该是本段的书页（可以是空的或已经有标题）。
- 帕秋莉：`drawPatchouli(c, { x, y, h, pose, mood, look, tilt, mouth, blink, t, facing, gesture })`，参数、姿势、表情、返回的锚点见 `src/character/patchouli.js` 文件头。嘴型用 `L.mouth`，眨眼用 `blinkAt(tau)`，表情默认 `L.mood`。身高 480–560，**脚底 y ≤ 900**（下面是字幕纸条）。不用 `stageChar`、`board`、`libraryBg`、`chapterTag`（第一版的）。
- 画具（`src/kit.js`）：`cutPaper`（剪纸片）、`rline`（墨线）、`zh`（手写字）、`brassPin`、`thread`、`popup`、`vellum`、`spin`、`chalkboard`/`chalk`（需要黑板时）、`fade`、`pop`、`sm`、`key`、`twos`、`writeP`、`drawMoonIcon`。颜色只用 `P`；书页纸色 `BOOK.page`。
- 字幕区 y ≈ 930–1030，不放要读的东西；书脊 `CX` 两侧 ±20 不放字。
- 纯函数、顶层名字带段前缀、只改自己的段文件、台词不改字、勤提交——同第一版。



目的和取舍见 `docs/方案.md`，每段的画面见 `docs/分镜.md`，台词出处见 `docs/内容来源.md`。

## 接口

- 所有脚本是经典 `<script>`，共享一个全局作用域。**段文件里的顶层名字都带本段前缀**（`S1`、`s1Clock`……），否则撞名整部片打不开。局部变量别叫 `W` `H` `P` `L` `Q` `c`（`c` 作参数除外）。
- 段文件末尾 `scene({ order, key, title, dur, lines, fn })`。`fn(c, tau, L)` 画本段第 `tau` 秒：
  - **纯函数**：画面只由 `tau` 决定，不许在闭包或全局里存状态（播放器会跳着取帧，出片会多页并行）。
  - `L` 是当前台词：`L.line` 文字、`L.lineT` 这句已经说了几秒、`L.lineP` 0..1、`L.mood` 表情、`L.mouth` 嘴型 0..1、`L.talking`。
  - 某句台词的开始时间：`S1LINES[3][0]`，结束时间 `S1LINES[3][1]`。画面节拍对齐台词，用这两个数，别写死秒数。
- 逻辑画面 1920×1080（`W` `H` `CX` `CY`）。字幕由 `film.js` 画在底部（基线 y=990，占 y≈930–1030），场景别在那里放要读的字。
- 讲台布局 `STAGE`：帕秋莉脚底 (360, 1040)、身高 860；魔导书页 `board(c, 700, 70, 1170, 790, { t, title })`，返回内容区 `{x, y, w, h}`。`stageChar(c, tau, L, {pose, mood...})` 在讲台位置画帕秋莉，嘴型和眨眼自动。
- 帕秋莉：`drawPatchouli(c, o)`、`drawPatchouliChibi(c, o)`，参数见 `src/character/patchouli.js` 文件头。现在是占位版，角色包交付后同一接口直接换上。**场景包别依赖占位版的具体长相**，只依赖锚点和尺寸。

## 画风规则

- **颜色**只用 `P`（`kit.js` 顶部）。好/坏用 `P.green` / `P.red`，白天 `P.sun` `P.sky`，夜里 `P.night` 系，重点 `P.moon`（金）。
- **线**用 `rline`，**形状**用 `rshape`（填色 + 手绘描边），传 `t: tau` 让线条每秒抖 8 次。不用 `fillRect` 画可见的形状（铺底色除外）。黑板上的图标、小人、图表都用这套线画，线宽 4–6，描边色 `P.ink`。
- **字**一律 `zh()`（霞鹜文楷）。黑板上的主文案字号 ≥ 44，小标注 ≥ 32。逐字写出用 `p: writeP(tau, t0, 文字)`。
- **动**：元素出现用 `pop` + `easeOutBack`（弹出）或 `rline` 的 `p` 画出来；消失干脆（0.2–0.3 秒）。同一时间黑板上最多 3 组信息，讲到下一个点时清掉上一个。每句台词至少有一个画面变化。
- **镜头**：需要满屏插图时直接画满屏（不用讲台布局），`c.translate/scale` 做推拉。满屏镜头每段 1–2 个，一个 3–8 秒。
- **段首段尾**：每段第 0–0.4 秒和最后 0.5 秒是标准讲台画面（图书馆 + 空白魔导书页 + 帕秋莉 lecture 姿势），这样段与段能直接切。段首 0.1 秒内出 `chapterTag`（开场和总结除外）。
- 例子贴近大学生：宿舍上下铺、熄灯后刷手机、外卖、奶茶、考试周、图书馆占座、久坐。

## 验收（每包自己做）

worktree 里没有 `node_modules` 和字体，先接上：

```sh
ln -s /home/user/patchouli-lecture-1/node_modules node_modules
cp /home/user/patchouli-lecture-1/fonts/LXGWWenKai-Regular.ttf fonts/
```

在仓库根目录运行，退出码 0 才算过：

```sh
node tools/frames.mjs --scene sleep --grid 36          # 本段联系表 → out/frames/sleep-grid.jpg
node tools/frames.mjs --scene sleep --at 3,20.5        # 本段整帧 → out/frames/sleep-3.png …
node tools/frames.mjs --grid 30                        # 全片能跑通
```

打开联系表和整帧自己看：没有空白、没有字被字幕挡住、字写完后停够、元素不出画、黑板不拥挤、画面和台词对得上。**勤提交**：每做完几句台词的画面、看过联系表没问题，就在自己分支上提交一次（`wip: <段> <做到哪>`）。
