「帕秋莉讲座」第 1 集：**我是帕秋莉，我来教你调理身体！**（第二版）

给大学生的 7 分钟调理身体科普，帕秋莉用中文油库里语音讲：睡眠、吃饭、动力、专注、运动，最后是四条极简清单。

第二版按 v0.1.0 的审看意见重做：克制、高抽象，但不简单。全片像《图画展览会》：一本摊在桌上的魔导书是贯穿的「漫步」主题，每一页换一种编配——剪纸灯箱、俯拍桌面定格、单线过山车、蓝晒星图、立体书——段与段之间形状接形状（月亮→盘子、线→线轨、火花→星星、星图→书页）。帕秋莉改成剪纸人偶。画面和角色全部由 Canvas 2D 代码逐帧绘制。

- `patchouli-lecture-1.html`：单文件网页，双击打开，不需要网络。空格暂停，←/→ 跳 5 秒，下方按钮切章节、开关语音和音乐。
- `patchouli-lecture-1.mp4`：1920×1080，30fps，中文油库里语音 + 字幕 + 背景音乐。

知识来源：[zijie0/HumanSystemOptimization](https://github.com/zijie0/HumanSystemOptimization)（整理自 Huberman Lab 播客），运动部分补充 WHO《关于身体活动和久坐行为的指南》（2020）。逐句出处见 `docs/内容来源.md`。

语音：AquesTalk（株式会社アクエスト）。本片是科普，不是诊断；身体不舒服请去校医院。东方 Project 角色版权归上海爱丽丝幻乐团，本片为同人作品。
